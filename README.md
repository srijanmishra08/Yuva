# YUVA Conference Portal — Deployment Guide

## Overview

**Conference:** YUVA Diplomacy Summit 2026 (YDS 2026)  
**Portal URL:** https://portal.funology.in  
**Landing URL:** https://yds.funology.club  
**Stack:** Next.js 14 · Supabase · Razorpay · Nodemailer · Vercel

---

## 1. Prerequisites

- Node.js 18+ 
- A [Supabase](https://supabase.com) project
- A [Razorpay](https://razorpay.com) account with live/test keys
- SMTP email credentials (Gmail App Password recommended)
- A [Vercel](https://vercel.com) account

---

## 2. Supabase Setup

### 2.1 Create Project
1. Go to [supabase.com](https://supabase.com) → New Project
2. Note your **Project URL**, **anon key**, and **service role key**

### 2.2 Run the Schema
1. Open your Supabase project → **SQL Editor**
2. Paste the contents of `supabase/schema.sql`
3. Click **Run**

This creates all tables, RLS policies, functions, and seed data.

### 2.3 Enable Email Auth
1. Go to **Authentication → Providers**
2. Enable **Email** with "Enable Email Confirmations" = OFF
3. Enable OTP (magic link) for delegate login

### 2.4 Create First Super Admin
```sql
-- Run in SQL Editor after creating user via Supabase Auth Dashboard
INSERT INTO admins (id, name, email, role)
VALUES (
  'your-auth-user-uuid-here',
  'Super Admin Name',
  'admin@funology.in',
  'SUPER_ADMIN'
);
```

## 3. Environment Variables

Copy `.env.local.example` to `.env.local` and fill in all values:

```env
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGc...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGc...

RAZORPAY_KEY_ID=rzp_live_xxxx
RAZORPAY_KEY_SECRET=xxxx
NEXT_PUBLIC_RAZORPAY_KEY_ID=rzp_live_xxxx

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=conference@funology.in
SMTP_PASS=your-16-char-app-password
SMTP_FROM=YUVA Diplomacy Summit <conference@funology.in>

HMAC_CHECKIN_SECRET=minimum-32-character-random-secret-here

NEXT_PUBLIC_APP_URL=https://portal.funology.in
NEXT_PUBLIC_LANDING_URL=https://yds.funology.club
```

### Gmail App Password
1. Enable 2FA on your Google account
2. Go to Google Account → Security → App Passwords
3. Generate password for "Mail"

## 5. Vercel Deployment

### 5.1 Connect Repository
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel

# Follow prompts to connect to your Vercel project
```

### 5.2 Add Environment Variables
In Vercel Dashboard → Project Settings → Environment Variables, add all variables from `.env.local`.

### 5.3 Configure Domains
1. Add `portal.funology.in` as a custom domain in Vercel
2. Point DNS: `portal CNAME cname.vercel-dns.com`

### 5.4 Razorpay Webhook
In Razorpay Dashboard → Settings → Webhooks:
- URL: `https://portal.funology.in/api/webhook/razorpay`
- Events: `payment.captured`, `payment.failed`
- Active: Yes

## 8. Security Notes

- **RLS enabled** on all Supabase tables
- Admin role cannot see email, phone, payment IDs
- QR codes use **HMAC-SHA256** tokens
- Razorpay webhooks verified with **HMAC signature**
- Service role key only used in API routes (server-side)
- Delegate passwords not stored — OTP-only login

---

## 9. Delegate ID Format

Auto-incrementing: `YDS26-001`, `YDS26-002`, ...  
Generated by PostgreSQL sequence function `generate_delegate_id()`.

---

## 10. Email System

Two email types:
1. **Registration Confirmation** — sent immediately after payment
2. **Allotment Confirmation** — sent when admin clicks "Send Confirmation"

Admins never see delegate email addresses — emails are sent server-side only.
